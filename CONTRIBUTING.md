# Contributing to English Conversation Memorization Site

Thank you for your interest in contributing! We welcome contributions to improve this project.

## How to Contribute

1.  **Fork the Repository**: specific to your GitHub account.
2.  **Create a Branch**: `git checkout -b feat/your-feature-name`
3.  **Make Changes**: Implement your feature or fix.
4.  **Commit Changes**: Use clear commit messages (e.g., `feat: Add new day content`, `fix: Typo in script.js`).
5.  **Push to Branch**: `git push origin feat/your-feature-name`
6.  **Open a Pull Request**: Submit your PR for review.

## Code Style

- **PHP**: Follow PSR-12 standards.
- **JavaScript**: Use modern ES6+ syntax. Ensure JSDoc comments are present for functions.
- **CSS**: Keep rules organized by component.

## Content Updates

If you are adding new conversation content:

- Edit `content.md`.
- Follow the format: `## DayXXX : Title` followed by Korean/English pairs.
- Ensure even number of lines in conversation blocks (Question/Answer pairs).
