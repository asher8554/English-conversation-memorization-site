# 텍스트 클릭 TTS 재생 개선 계획

## 목표

질문 한글 텍스트를 클릭하면 현재 질문을 한국어 음성으로 다시 읽고, 답변 영문 텍스트를 클릭하면 현재 답변을 영어 음성으로 다시 읽는다.

## 성공 기준

1. 질문 텍스트 클릭 시 `TTSManager.speak`가 현재 질문과 `ko-KR`로 호출된다.
2. 답변 텍스트 클릭 시 `TTSManager.speak`가 현재 답변과 `en-US`로 호출된다.
3. 자동 읽기 설정과 별개로 수동 클릭 재생이 동작한다.
4. 기존 자동 질문 읽기와 Show Answer 자동 답변 읽기 동작은 유지된다.
5. `node --test`와 `node --check script.js`가 통과한다.

## 구현 순서

1. DOM 테스트 스텁에 클릭 이벤트와 음성 호출 기록을 추가한다.
2. 구현 전 질문과 답변 클릭 재생 테스트가 실패하는지 확인한다.
3. `QuizApp`에 질문과 답변 텍스트 클릭 핸들러를 추가한다.
4. 현재 텍스트가 비어 있으면 재생하지 않는 작은 보호 로직을 둔다.
5. 테스트와 브라우저 렌더링 흐름으로 검증한다.

## 범위

이번 작업은 `script.js`, `tests/quiz-rendering.test.js`, 작업 로그 문서만 수정한다. TTS 음성 선택, 속도 설정, 데이터 구조, 화면 배치 변경은 포함하지 않는다.
