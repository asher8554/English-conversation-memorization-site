# 기본동사 Further Studies 표시 계획

## 목표

기본동사 코스에서 Notion의 `Further Studies` 문장들이 실제 문제 카드로 나오고, 카드 화면에서도 현재 섹션명이 보이게 한다.

## 확인한 원인

- 라이브 Day 001에는 12개 카드만 있고 `Further Studies` 문장이 없다.
- 기존 `data.json`은 카드별 섹션 정보를 저장하지 않는다.
- `script.js`는 섹션형 데이터 정규화는 지원하지만, 렌더링 시 섹션 라벨을 표시하지 않는다.

## 작업

1. 정규화 함수가 섹션형 데이터의 카드에 `section`을 보존하는 테스트를 추가한다.
2. 카드 렌더링이 `section`을 표시하는 테스트를 추가한다.
3. Notion에서 Day 001~035를 섹션 포함 형태로 다시 추출해 `data.json`에 반영한다.
4. 빈 `Further Studies` 섹션은 계속 제외한다.
5. 캐시 버전을 갱신하고 로컬, 라이브에서 `Further Studies`가 표시되는지 확인한다.
