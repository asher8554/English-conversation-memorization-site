# 기본동사 Day 026~035 반영 계획

## 목표

Notion 원문에는 기본동사 Day 026~035가 입력되어 있지만 배포 사이트는 Day 025까지만 표시되는 문제를 해결한다.

## 확인한 원인

- 라이브 `data.json`과 로컬 `data.json` 모두 `basic-verbs`가 Day 025에서 끝난다.
- Notion 페이지 recordMap에는 Day 026~035 헤딩이 존재한다.
- 이전 작업 당시 Day 026은 빈 템플릿이라 제외됐지만, 지금은 Notion 원문이 업데이트됐다.

## 작업

1. `basic-verbs` 데이터가 Day 026~035까지 포함되어야 한다는 실패 테스트를 추가한다.
2. Notion recordMap에서 Day 026~035의 한국어, 영어 문장쌍을 추출한다.
3. `data.json`의 `basic-verbs.data`와 `dayMainSentences`에 Day 026~035를 추가한다.
4. `data.json` 캐시 버전을 올려 GitHub Pages에서 새 데이터를 받게 한다.
5. 테스트와 브라우저, 라이브 데이터 확인 후 커밋하고 push한다.

## 제외

- Day00x 빈 템플릿은 실제 학습 데이터가 아니므로 추가하지 않는다.
- 기존 영어회화 데이터와 UI 구조는 변경하지 않는다.
